# Scholarship Application Checklist & Timeline

A comprehensive guide to staying organized throughout your application process.

---

## 🗓️ 6 Months Before Deadline

- [ ] Research scholarships matching your profile (nationality, field of study, degree level)
- [ ] Create a master spreadsheet with deadlines, requirements, and award amounts
- [ ] Identify 3–5 target programs (dream, match, safety)
- [ ] Check language proficiency requirements (TOEFL, IELTS)
- [ ] Register for required standardized tests (GRE, GMAT, LSAT, etc.)

---

## 🗓️ 4 Months Before Deadline

- [ ] Request academic transcripts from all previous institutions
- [ ] Arrange translation of transcripts (if required)
- [ ] Identify 2–3 professors/employers for recommendation letters
- [ ] Send recommendation requests early with all necessary forms
- [ ] Start drafting personal statement / scholarship essay
- [ ] Research specific professors or programs at target universities

---

## 🗓️ 3 Months Before Deadline

- [ ] Complete first draft of all essays
- [ ] Share essays with mentors, advisors, or writing centers for feedback
- [ ] Customize each essay for the specific scholarship (mission alignment)
- [ ] Revise and polish essay drafts
- [ ] Prepare CV / resume tailored to each scholarship
- [ ] Take standardized tests (allow 2 weeks for score delivery)

---

## 🗓️ 6 Weeks Before Deadline

- [ ] Finalize all essays and proofread
- [ ] Request final versions of recommendation letters
- [ ] Complete application forms (online and/or paper)
- [ ] Prepare additional materials (portfolio, research proposal, etc.)
- [ ] Start filling out financial aid forms (FAFSA, CSS Profile if applicable)

---

## 🗓️ 2 Weeks Before Deadline

- [ ] Review entire application package for completeness
- [ ] Submit test scores officially to the institution/program
- [ ] Ensure recommendation letters have been submitted
- [ ] Submit application online (avoid waiting until the last day!)
- [ ] Save all submission confirmations and receipts

---

## ✅ After Submission

- [ ] Send thank-you emails to recommenders
- [ ] Follow up with the program office to confirm receipt
- [ ] Prepare for potential interviews (research common questions)
- [ ] Track deadlines for final decisions
- [ ] Plan financial alternatives (backup options)

---

## 📝 Pro Tips

- **Start Early:** Most programs are highly competitive — early preparation is key.
- **Organize Digitally:** Use cloud storage for all documents (Google Drive, Dropbox).
- **Check Regularly:** Scholarship details change. Revisit official websites weekly.
- **Prepare Multiple Essays:** Do not reuse identical essays for different programs.
