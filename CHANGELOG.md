# Changelog

## [1.0.0] - 2026-09-02

### Added
- Initial release of the U.S. Scholarships & Financial Aid Guide
- Complete `README.md` with project overview, structure, and navigation
- Comprehensive `SOURCES.md` with 30+ verified official references
- Full `GUIDE.md` with detailed program descriptions and sample essay
- MIT `LICENSE` file
- Essay template in `/essays/scholarship-essay-template.md`
- Application checklist in `/checklists/application-checklist.md`
- Structured JSON data in `/data/scholarships.json`

### Categories Included
- 4 Official databases (EducationUSA, IIE, IEFA, Scholars4Dev)
- 2 U.S. government programs (Fulbright, Humphrey)
- 3 Foundation scholarships (AAUW, Knight-Hennessy, Rotary)
- 6 University need-blind institutions
- 3 ABD dissertation fellowships
- Sample essay framework and execution plan
